# JoGo-Metric-Jumps

**Jo⚡Go Metric Jumps** — a Grade 4 metric length conversion game (km · m · cm · mm)
built around dragging the decimal comma.

The complete application lives in:

```
output/jo-go-metric-jumps/
```

See `output/jo-go-metric-jumps/README.md` for how to play, the learning design,
and how to run the automated test suite (`node tests/run-tests.js`).
