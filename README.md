# JoGo-Metric-Jumps

**Jo⚡Go Metric Jumps** — a Grade 4 metric conversion game covering length
(km · m · cm · mm), mass (kg · g · mg) and volume (kL · L · mL), built around
dragging the decimal comma, plus a physical-scales reading lab (ruler, kitchen
scale, measuring jug), teacher tools and printable/PDF worksheets.

The complete application lives in:

```
output/jo-go-metric-jumps/
```

**New to this repo (human or AI)? Read [`PLAYBOOK.md`](PLAYBOOK.md) first.**
It captures how the app was actually built — the process rules, the
reverse-engineered master prompt, and the bug catalog — so future builders
inherit the whole journey instead of reinventing it.
